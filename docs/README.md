# 使用说明（写给第一次接触的人）

这是一套「从公司 Confluence 知识里，给出**可追溯**回答」的系统。你问一个业务问题，它不只给答案，还告诉你**这句话是从哪来的**。

这几份说明是**非技术**的，看不懂代码也能用。建议按顺序读前两份，其余按需查。

## 一分钟看懂

- **两条知识线并行**：
  - **卡片**（审批卡）= 把零散原文提炼成一张张"词条卡"，像查字典，快。
  - **RAG** = 把每页切成小段存进检索库，问问题时按相关度召回原文段落，可逐句追溯。
- **回答时可以选用哪条线**（或让系统自动选）——这就是「三种回答模式」。
- 答案下面永远有一块**「证据来源」**，告诉你这次是查了卡片、回了原文、还是全库检索，方便你判断可不可信。

## 一句话提醒

页面顶部如果出现**红色斜纹警示条**或**红色 DEMO 字样**，说明你现在看到的是**脱敏演示数据，不是真实内网知识**。汇报、决策前请先确认它消失了（详见 [01](01_系统是什么与快速上手.md) 最后一节）。
