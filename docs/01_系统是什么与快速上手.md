# 01 · 系统是什么 & 快速上手

## 它解决什么问题

公司知识散落在很多 Confluence 页面里，找答案靠人翻、靠记忆，容易找错、找不全。这个系统把这些知识整理好，让你**用大白话问问题，拿到带出处的回答**——每个答案都能点回到原文段落，不是凭空编的。

它现在是一个 **PoC（概念验证）**：核心链路都能跑通，用来演示和评估"这条路走不走得通"，还不是最终上线的成品。

## 两条知识线（先理解这个，后面都好懂）

| | 卡片（审批卡） | RAG |
|---|---|---|
| 是什么 | 把多页原文里讲同一件事的内容，提炼成一张"词条卡"（主题 → 小节 → 一条条事实 → 出处） | 把每页切成很多小段，存进一个可按相关度搜索的库 |
| 像什么 | 像查字典 / 词条 | 像全文搜索 + 摘要 |
| 强在哪 | 快、结构清楚、能看出知识之间的关系 | 覆盖全、答案能逐句追回原文 |
| 弱在哪 | 受"提炼得准不准"影响（卡片保真度） | 受"搜得准不准"影响（可能漏或混入无关段落） |

回答问题时，你可以指定用哪条线，或者让系统**自动选**。这就是 [03 · 三种回答模式](03_三种回答模式.md) 要讲的事。

## 四个页面，一句话各是什么

| 页面（顶部/链接名） | 干什么用 |
|---|---|
| **实时问答**（主页） | 提问、看答案、看"它是怎么得出这个答案的"（执行轨迹 + 证据来源） |
| **评估看板**（主页内切换） | 把几种回答方案放一起比分数，看谁更靠谱 |
| **卡片路径** / Card Explorer | 翻看一张张卡片的内部结构，和一次回答的"下钻路线图"、知识地图 |
| **词表审批 / 候选 topic 审批**（审批页） | 维护知识的"骨架"：确认新主题、合并重复；**复核字段冲突**（同一字段出现多个值时，红色提示，人工拍板） |
| **Cards 流程图解**（flow） | 用图讲清楚"卡片是怎么建出来、又怎么被查到的"，适合汇报/科普 |

## 第一次打开，走一遍（5 步）

1. 打开**实时问答**主页。右上角看一眼状态：显示"已连接后端"就 OK。
2. 左边保持默认的 **Golden Set**（系统预置的标准问题），从下拉里选一个问题。
3. 回答方式保持默认的 **Agentic（自动路由）**。
4. 点 **开始回答**。右边会先一步步亮出"执行轨迹"，再流式吐出答案。
5. 答案下面看两样东西：
   - **GOLD ANSWER**（人工核验的标准答案）vs **LLM ANSWER**（系统的回答）——对比一下准不准。
   - **证据来源**那一块——告诉你这次答案是基于卡片字段、原文段落、还是全库检索。

想换成自己的问题：把左上角切到 **自由提问**，在"当前问题"里输入，再点开始回答。

## 怎么判断"这是不是真数据"（重要）

这套系统带了一份**脱敏演示数据**，方便没连内网时也能演示。但演示数据 ≠ 真实知识，别拿它去汇报或做决策。识别方法：

- **页面顶部出现红色斜纹警示条 / 红色 "DEMO / 合成数据" 字样** → 当前是演示/合成数据。
- 卡片页顶部出现**「⚠ 脱敏 DEMO 卡片」**红条 → 卡片不是真实内网数据。
- 一切正常（真实数据）时，这些红条**都不出现**，卡片页"数据源"小框会显示"N 张真实卡"（绿色）。

看到红条不用慌，它只是提醒；要换成真实数据是维护同事的事（见 [04](04_知识库增删改流程.md)）。
