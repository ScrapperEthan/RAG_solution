# 03 · 三种回答模式怎么选

在主问答页，左侧「回答方式（三族）」让你选系统用哪条知识线回答。再加一个"对照基线"，一共四种走法。这份说明讲清楚**它们怎么工作、有多可信、各自的短板、什么时候用哪个**。

## 先看一张对比表

| 模式 | 怎么回答（大白话） | 可靠程度 | 能逐句追溯吗 | 最适合 | 主要短板 |
|---|---|---|---|---|---|
| **对照基线**：模型直答 | 大模型只凭自己脑子答，不看公司知识 | ★☆☆☆☆ 最低 | 否 | 只作对照、看"不接知识会怎样" | 可能一本正经地编（幻觉） |
| **卡片直答** | 直接读卡片里已提炼好的字段值，不回原文 | ★★★☆☆ 中 | 否 | 快速查词条式问题；**校验卡片里写得对不对** | 卡片错就跟着错（受卡片保真度限制） |
| **RAG**：检索原文生成 | 从原文小段里检索 + 让大模型据此生成 | ★★★★☆ 中高 | 是 | 覆盖广、要回到原文的问题 | 受检索好坏影响，可能漏检或混入无关段落 |
| **卡片 + 回原文取证** | 卡片先定位主题，答案回到原文段落逐句生成 | ★★★★★ 高 | 是 | 精确值、有争议、要可追溯的问题 | 比直答慢一点；需要卡片+原文都到位 |
| **Agentic**：自动路由（推荐） | 系统自己判断问题类型，自动选上面的路；卡片钻不到就回退 RAG | ★★★★☆ 高（综合） | 多数是 | 不想纠结时的默认选择 | 偶尔路由判断不理想；过程更复杂 |

★ 越多越可信。"可靠程度"是一般情况下的相对高低，不是绝对保证。

## 逐个说清楚

### 对照基线 · 模型直答（无 grounding）
- **怎么工作**：完全不看公司知识，纯靠大模型预训练的知识回答。
- **为什么留着它**：做对照。让你直观看到"不接知识库时，模型会怎么答、会不会编"。
- **可靠程度**：最低。可能流畅地说出**听起来对、其实没依据**的话。
- **什么时候用**：演示对比时。**不要**当正式答案用。

### 卡片直答（卡片库子模式）
- **怎么工作**：直接读卡片里 reduce 已经提炼好的字段值，**不回原文**。
- **可靠程度**：中。**完全取决于卡片本身准不准**（卡片保真度）。卡片对 → 又快又准；卡片在提炼时出了偏差 → 答案就跟着错，而且因为没回原文，你不能逐句核对。
- **一个重要用途——校验卡片内容**：正因为它"原样吐出卡片里写的值"，它特别适合用来**检查卡片本身对不对**。做法：同一个问题，先用"卡片直答"看卡片怎么说，再用"卡片 + 回原文取证"看原文怎么说，两者一对比，就能发现卡片有没有提炼错。
- **什么时候用**：查"卡片里记的某个值是多少"这种词条式问题；或专门校验卡片质量时。

### RAG · 检索原文生成
- **怎么工作**：把问题拿去原文小段库里检索出最相关的几段，让大模型**只根据这几段**生成答案，并给出处。
- **可靠程度**：中高。答案能追回原文段落，比较踏实；但**成也检索败也检索**——如果该检索的段落没被召回，或召回了无关段落，答案质量会受影响。
- **什么时候用**：覆盖面广、不一定有现成卡片、需要回到原文的问题。

### 卡片 + 回原文取证（卡片库子模式）
- **怎么工作**：先用卡片**快速定位**到正确主题，再**回到 Confluence 原文段落**逐句取证生成答案。卡片管"找对地方"，原文管"逐句负责"。
- **可靠程度**：高。既有卡片的精准定位，又有原文的逐句可追溯。
- **什么时候用**：精确数值、有争议、必须能追溯出处的问题。是"要对结果负责"时的首选。

### Agentic · 自动路由（推荐默认）
- **怎么工作**：系统先判断你这个问题是"要精确值"还是"要概念解释"等类型，自动选最合适的路；而且当卡片下钻**失败/覆盖不全**时，会自动**回退到 RAG** 兜底，避免直接放弃。
- **可靠程度**：综合最稳，所以设为默认。
- **什么时候用**：日常默认用它就行。只有当你想**指定**某条路（比如专门校验卡片）时，才手动切到别的模式。

## 怎么快速决定用哪个

- 不想纠结 → **Agentic**。
- 想要最可追溯、对结果负责 → **卡片 + 回原文取证**。
- 想知道"卡片里到底写了啥"或想校验卡片 → **卡片直答**。
- 没有现成卡片、想广撒网回到原文 → **RAG**。
- 想看"不接知识会怎样" → **对照基线**（仅对比）。

## 共同提醒
- 不管哪种模式，都**先看答案下面的「证据来源」标签**再决定信不信。
- 看到"无可验证证据 / NO_ANSWER" 是系统在**拒绝瞎编**，属于正常且安全的行为。
- 这些可靠程度是"现状下的相对高低"，会随知识质量、检索效果变化——所以才需要 [评估看板] 持续跑分、需要 [04] 的维护流程把知识喂准。
