## Template Governance and Maintenance

Template Maintenance covers how message templates are created and governed, and
how each template is recorded in the message inventory.

| Template Step | Owner | Tool |
|---|---|---|
| create template in portal | content team | MDC portal |
| message Inventory | governance team | governance tool |

## Testing, bounce back, and retry

Testing confirms a use case end to end before go-live. Undeliverable messages are
handled by bounce back and retry.

| Mechanism | Behaviour | Owner |
|---|---|---|
| Bounce Back Handling | mark undeliverable | ops team |
| Resend / Retry Mechanism | scheduled retry | ops team |

For the exact retry counts and timing, refer to the Message Path Service Catalogue.
