## Message Path Service Catalogue

Each notification use case runs over a message path with a published service
standard. The catalogue lists the baseline SLO and the actual performance rate.

| Message Path | service baseline SLO | actual performance rate |
|---|---|---|
| M488 payment path | 5 min | 4.2 min |
| M489 statement path | 30 min | 22 min |
